Email signature with icons
1. Open email-signature.html in a browser to preview (keep the icons folder next to it).
2. Gmail/Outlook cannot load local images, so upload the 6 PNGs in "icons" to a public place
   (e.g. a public GitHub repo, files viewed via raw.githubusercontent.com).
3. In email-signature.html replace  icons/  with your hosted URL, e.g.
   https://raw.githubusercontent.com/naqeeb74/email-signature-icons/main/
4. Open the file in a browser, select the signature, copy, paste into your email signature settings.
